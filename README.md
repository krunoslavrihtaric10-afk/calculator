# Calculator App

## Description
This is a simple Python calculator application that allows you to perform basic mathematical operations: addition, subtraction, multiplication, and division.  

## How to Run
1. Download or clone the repository:
   ```bash
   git clone https://github.com/krunoslavrihtaric10-afk/calculator.git
2. Navigate to the project folder:
   cd calculator
3. Run the application:
   python calculator.py
4. Follow the instructions in the terminal.

Technologies:
   Python 3.x

Features:
Addition, subtraction, multiplication, and division

Terminal-based operation

Simple interface
